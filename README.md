# Techflow Solutions — лендинг

Одностраничный сайт производителя добавок для бетонных смесей (Астана).
Статические файлы, без сборки. Открывается напрямую или с любого хостинга.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка страницы и весь контент |
| `styles.css` | Стили, брендовая палитра (navy + periwinkle), адаптив |
| `main.js` | Меню на мобильных, появление секций при скролле, отправка формы |
| `assets/` | Фото объектов, favicon, исходные версии логотипа из PDF |

## Разделы

Шапка с логотипом · Hero · Показатели · О компании · Преимущества
поликарбоксилатов · Таблица применимости продукции · Объекты · Блок
CTA · Контакты с формой и картой · Футер.

Контент взят из презентации «Техфлоу 2026». Логотип в меню перерисован
в SVG (чёткий на любом экране, меняет цвет под тёмный футер).
Исходные растровые версии — `assets/logo-white.png`, `assets/logo-navy.jpg`.

### Фон главного экрана

На Hero стоит фото ТРЦ MEGA Silk Way (`assets/hero-mega.jpg` +
`hero-mega-1100.jpg` для мобильных). Готова замена на EXPO-2017 —
`assets/hero-expo.jpg`: в `index.html` в блоке `.hero__bg` поменяйте
`src` / `srcset` на `hero-expo.jpg` и обновите `alt` и подпись
`.hero__caption`. Исходные фото объектов — в презентации; если нужен
кадр выше по разрешению, замените файл тем же именем.

## Запуск локально

Просто откройте `index.html` в браузере. Для корректной работы карты и
формы лучше поднять локальный сервер:

```
python -m http.server 8000
```

и открыть `http://localhost:8000`.

## Что стоит доработать перед продакшеном

1. **Шрифты.** Сейчас Onest / JetBrains Mono / Fredoka подключены с Google
   Fonts. Для скорости и приватности — скачать и положить в `assets/fonts`,
   подключить через `@font-face`.
2. **Форма заявки.** Кнопка «Отправить заявку» открывает почтовый клиент
   (`mailto:`). Для приёма заявок на сервере подключите обработчик
   (Formspree, собственный endpoint, CRM) в `main.js`.
3. **Карта.** Вставлен встроенный Google Maps по адресу. При необходимости
   заменить на 2ГИС / Яндекс.Карты или точную точку с меткой.
4. **Иконки.** Набор Phosphor Icons подключён с CDN. Можно локализовать.
5. **Юр. данные.** В футере указан только город. Добавьте полное
   наименование компании, БИН и т.п., если нужно.
6. Заполните `og:image` и добавьте `sitemap.xml` / `robots.txt`.
